# 小说平台 · 数据库设计

> 面向 Java Spring Boot 3 + MyBatis-Plus + MySQL 8 后端。
> 所有字段命名与前端 `novel-front-web` 完全对齐(下方附"JSON 字段 ↔ 数据库字段"对照表)。

---

## 1. 通用约定

| 项 | 约定 |
|---|---|
| 存储引擎 / 字符集 | InnoDB / `utf8mb4` |
| 主键 | `BIGINT AUTO_INCREMENT`(学习型够用;生产可换雪花 ID) |
| 时间字段 | `DATETIME`,默认 `CURRENT_TIMESTAMP` |
| 金额 | 一律存 **整数"分"**(`INT`),避免浮点误差 |
| 逻辑状态 | `0/1` 语义与前端一致(见每表注释) |
| 冗余字段 | `book_info` 冗余分类名/作者名/最新章节名,换取列表页免联表 |
| 命名 | 表/列 小写下划线;JSON 驼峰(MyBatis-Plus 默认自动映射) |

---

## 2. 实体关系(ER)总览

```
sys_user 1 ──── n author_info            (一个用户申请成为作家)
sys_user 1 ──── n user_bookshelf         (书架)
sys_user 1 ──── n user_read_history      (阅读历史)
sys_user 1 ──── n book_comment           (发评论)
sys_user 1 ──── n pay_order / user_subscription

book_category 1 ──── n book_info
author_info  1 ──── n book_info
book_info    1 ──── n book_chapter ── 1:1 ── book_content
book_info    1 ──── n book_comment  ── 1:n ── book_comment_reply
book_info    1 ──── n home_book / user_bookshelf / user_read_history / user_subscription

news_category 1 ──── n news_info
sys_user      1 ──── n user_feedback
```

## 3. 建表语句(DDL)

### 3.1 用户 `sys_user`
```sql
CREATE TABLE sys_user (
  id            BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
  username      VARCHAR(64)  NOT NULL COMMENT '用户名(手机号)，登录账号',
  password      VARCHAR(100) NOT NULL COMMENT '密码(BCrypt 加密)',
  nick_name     VARCHAR(64)  NOT NULL COMMENT '昵称',
  user_photo    VARCHAR(255) DEFAULT NULL COMMENT '头像(相对路径)',
  user_sex      TINYINT      NOT NULL DEFAULT 0 COMMENT '性别 0男 1女',
  user_birthday DATE         DEFAULT NULL COMMENT '生日',
  user_phone    VARCHAR(20)  DEFAULT NULL COMMENT '手机号',
  user_email    VARCHAR(64)  DEFAULT NULL COMMENT '邮箱',
  balance       INT          NOT NULL DEFAULT 0 COMMENT '余额(分)',
  status        TINYINT      NOT NULL DEFAULT 0 COMMENT '状态 0正常 1禁用',
  create_time   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  update_time   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (id),
  UNIQUE KEY uk_username (username)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

## 4. JSON 字段 ↔ 数据库字段 对照表

> 前端接口返回驼峰字段;MyBatis-Plus 开启 `map-underscore-to-camel-case` 后自动映射。下面列出关键映射,写接口时以此为准。

| 前端 JSON 字段 | 数据库列 | 说明 |
|---|---|---|
| `bookStatus` | `book_info.book_status` | 0连载 1完结 |
| `categoryName` | `book_info.category_name` | 冗余 |
| `lastChapterName` | `book_info.last_chapter_name` | 冗余 |
| `lastChapterUpdateTime` | `book_info.last_chapter_update_time` | 冗余,更新榜单用 |
| `firstChapterId` | `book_info.first_chapter_id` | "点击阅读"跳转 |
| `wordCount` | `book_info.word_count` | 前端做"万/千"格式化 |
| `visitCount` | `book_info.visit_count` | |
| `picUrl` | `book_info.pic_url` | 相对路径,前端拼 imgBaseUrl |
| `isVip` | `book_chapter.is_vip` / `book_info.is_vip` | 0免费 1收费 |
| `chapterName` | `book_chapter.chapter_name` | |
| `chapterWordCount` | `book_chapter.chapter_word_count` | |
| `chapterUpdateTime` | `book_chapter.chapter_update_time` | |
| `bookContent` | `book_content.content` | 正文 |
| `type` | `home_book.type` | 0轮播 1顶栏 2本周强推 3热门 4精品 |
| `commentTotal` | 评论数(计数) | |
| `commentUser` | `book_comment.comment_user_name` | 冗余 |
| `updateTime`(作家后台) | `book_info.update_time` | |

## 5. 关键业务规则

1. **点击量**:`/front/book/visit` 每次 `visit_count + 1`(可异步/Redis 累加后定时落库)。
2. **最新章节冗余**:发布新章节时,事务内同时更新 `book_info.last_chapter_id / last_chapter_name / last_chapter_update_time / word_count / first_chapter_id(首章发布时)`。
3. **VIP 判断**:`/front/book/content/{chapterId}` 返回正文前,若 `chapter.is_vip=1` 且当前用户无 `user_subscription` 记录(该 chapter_id 或整本 book_id),则返回"未订阅"错误码,不返回正文。
4. **订阅扣款**:购买时校验 `sys_user.balance >= chapter_price`,事务内扣余额 + 写 `user_subscription`。
5. **搜索排序**:`sort=word_count|visit_count|last_chapter_update_time`,对应 `book_info` 三个索引列,支持 LIMIT 分页。

## 6. 扩展说明(进阶,暂不实现)

- **正文分表/对象存储**:章节量大时,`book_content` 可按 `chapter_id` 哈希分表(原项目用 ShardingSphere),或正文存对象存储只留路径。
- **全文搜索**:书名/作者模糊匹配先用 `LIKE`,量级上来再上 Elasticsearch。
- **余额流水**:若需审计,把 `sys_user.balance` 拆成 `user_balance`(余额)+ `user_balance_log`(流水)两张表。
- **RBAC**:管理后台多角色时,增加 `sys_role` / `sys_user_role` / `sys_permission`。
