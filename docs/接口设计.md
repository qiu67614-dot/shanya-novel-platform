# 小说平台 · 接口设计文档

> 后端接口规范。字段命名与前端 `novel-front-web` 完全一致,可直接作为前后端联调的验收标准。
> 标注 ✅ = 前端已有调用(后端必须实现);🆕 = 新功能(前端页面在 M2/M3 阶段补充)。

---

## 1. 通用规范

### 1.1 基础信息
- **Base URL**:`/api`(前端 axios `baseURL`,见 `.env` 的 `VUE_APP_BASE_API_URL`)
- **协议**:HTTP/JSON,UTF-8
- **图片**:后端返回**相对路径**,前端用 `VUE_APP_BASE_IMG_URL` 拼接

### 1.2 统一响应体
所有接口返回:
```json
{ "code": "00000", "data": {}, "message": "成功" }
```
- `code`:**字符串**类型(前端用 `== "00000"` 判断,类型必须一致)
- `data`:业务数据(可为对象、数组、null)
- `message`:提示信息

### 1.3 认证方式
- 登录后签发 JWT,前端存 `localStorage`,请求头 `Authorization` 直接携带 token(**无 `Bearer` 前缀**)
- 需登录接口:`/front/user/**`(除 login/register)、`/author/**`、`/pay/**`、`/admin/**`
- 登录过期:返回 `code = "A0230"`,前端自动清 token 跳登录页

### 1.4 分页约定
请求参数 `pageNum`(页码,从 1 开始)+ `pageSize`(每页条数);响应:
```json
{ "code": "00000", "data": { "list": [], "pageNum": 1, "pageSize": 10, "total": 0 } }
```

## 2. 错误码表

| code | 含义 | 前端行为 |
|---|---|---|
| `00000` | 成功 | 正常处理 |
| `A0230` | 登录已过期/未登录 | 清 token 跳登录页 |
| `A0001` | 用户名或密码错误 | 弹 message |
| `A0002` | 验证码错误 | 弹 message |
| `A0003` | 手机号已注册 | 弹 message |
| `A0200` | 无权限(非作家/非管理员) | 弹 message |
| `B0001` | 章节未订阅 | 前端引导充值/购买 |
| `B0002` | 余额不足 | 弹 message |
| `B0003` | 资源不存在 | 弹 message |
| `A0400` | 参数校验失败 | 弹 message |

## 3. 门户接口 `/front`

### 3.1 首页推荐位 ✅
`GET /front/home/books` — 免登录
响应 `data`(数组),元素字段:

| 字段 | 类型 | 说明 |
|---|---|---|
| type | int | 0轮播 1顶栏 2本周强推 3热门推荐 4精品推荐 |
| bookId | long | 作品ID |
| bookName | string | 书名 |
| picUrl | string | 封面相对路径 |
| authorName | string | 作者 |
| bookDesc | string | 简介 |

### 3.2 友情链接 ✅
`GET /front/home/friend_Link/list` — 免登录
`data`:数组 `[{ linkName, linkUrl }]`

### 3.3 分类列表 ✅
`GET /front/book/category/list?workDirection=0` — 免登录
`data`:数组 `[{ id, name, workDirection }]`

### 3.4 搜索/作品列表 ✅
`GET /front/search/books` — 免登录
请求参数:

| 参数 | 类型 | 说明 |
|---|---|---|
| keyword | string | 书名/作者关键字 |
| workDirection | int | 0男频 1女频 |
| categoryId | long | 分类ID |
| bookStatus | int | 0连载 1完结 |
| wordCountMin / wordCountMax | long | 字数区间 |
| updateTimeMin | string | 更新时间下限(如 `2026-09-04`) |
| sort | string | `word_count` / `visit_count` / `last_chapter_update_time` |
| pageNum / pageSize | int | 分页 |

响应 `data`:分页对象,`list` 元素字段:

| 字段 | 说明 |
|---|---|
| id / categoryName / bookName / lastChapterName / authorName / wordCount | 列表展示字段 |

### 3.5 图书详情 ✅
`GET /front/book/{id}` — 免登录
`data` 字段:

| 字段 | 说明 |
|---|---|
| id | 作品ID |
| bookName / authorName / categoryName | 书名/作者/分类 |
| bookStatus | 0连载 1完结 |
| visitCount / wordCount | 点击量/字数 |
| bookDesc | 简介 |
| picUrl | 封面 |
| firstChapterId | 首章ID(点击阅读跳转) |

### 3.6 增加点击量 ✅
`POST /front/book/visit` — 免登录,body `{ bookId }`,`data` 为 null

### 3.7 最新章节摘要 ✅
`GET /front/book/last_chapter/about?bookId=` — 免登录
```json
{
  "chapterTotal": 320,
  "chapterInfo": { "bookId": 1, "id": 10021, "chapterName": "第20章 远方", "chapterUpdateTime": "2026-09-07 12:00:00" },
  "contentSummary": "夜色如墨，远处的山峦……"
}
```

### 3.8 同类推荐 ✅
`GET /front/book/rec_list?bookId=` — 免登录
`data`:数组 `[{ id, picUrl, bookName, bookDesc }]`

### 3.9 章节目录(门户)✅
`GET /front/book/chapter/list?bookId=` — 免登录
`data`:数组 `[{ id, chapterName, isVip, chapterNum }]`(按章节序号升序)

### 3.10 章节正文 ✅
`GET /front/book/content/{chapterId}` — 免登录(免费章)/需登录(付费章)
```json
{
  "chapterInfo": { "bookId": 1, "chapterName": "第1章 风起", "chapterWordCount": 3200, "chapterUpdateTime": "..." },
  "bookInfo": { "categoryName": "玄幻", "authorName": "天蚕土豆" },
  "bookContent": "　　夜色如墨……"
}
```
> 付费章未订阅时返回 `code=B0001`,不返回 `bookContent`。

### 3.11 上一章 / 下一章 ✅
`GET /front/book/pre_chapter_id/{chapterId}` / `next_chapter_id/{chapterId}` — 免登录
`data`:上一章/下一章的章节ID(`long`);无则 `null`

### 3.12 三个榜单 ✅
| 接口 | 说明 |
|---|---|
| `GET /front/book/visit_rank` | 点击榜(按 visitCount 降序) |
| `GET /front/book/newest_rank` | 新书榜(按 id 降序) |
| `GET /front/book/update_rank` | 更新榜(按 lastChapterUpdateTime 降序) |

`data`:数组,元素字段 `id, bookName, picUrl, bookDesc, categoryName, lastChapterName, authorName, wordCount, lastChapterUpdateTime`(榜单详情页 + 右侧小榜都取同一份)

### 3.13 最新评论 ✅
`GET /front/book/comment/newest_list?bookId=` — 免登录
```json
{
  "commentTotal": 3,
  "comments": [
    { "id": 1, "commentUserId": 1001, "commentUser": "书友小明", "commentUserPhoto": "", "commentContent": "太好看了", "commentTime": "2026-09-07 10:00:00" }
  ]
}
```

### 3.14 新闻 ✅
- `GET /front/news/latest_list` — 免登录,`data` 数组 `[{ id, categoryName, title }]`
- `GET /front/news/{id}` — 免登录,`data`:`{ title, sourceName, updateTime, content }`

### 3.15 图形验证码 ✅
`GET /front/resource/img_verify_code` — 免登录
`data`:`{ img: "<base64 PNG, 不含 data: 前缀>", sessionId: "<会话ID>" }`(注册时回传 sessionId 校验)

### 3.16 图片上传 ✅
`POST /front/resource/image` — 需登录,`multipart/form-data`,字段 `file`
`data`:`"<图片相对路径>"`(用于头像/封面上传,`el-upload` 直连)

## 4. 用户接口 `/front/user`

### 4.1 注册 ✅
`POST /front/user/register` — 免登录
body:`{ username(手机号), password, velCode(4位验证码), sessionId }`
`data`:`{ token, uid }`

### 4.2 登录 ✅
`POST /front/user/login` — 免登录
body:`{ username, password }`
`data`:`{ token, uid, nickName }`

### 4.3 获取用户信息 ✅
`GET /front/user` — 需登录
`data`:`{ id, username, nickName, userPhoto, userSex, userEmail, ... }`

### 4.4 更新用户信息 ✅
`PUT /front/user` — 需登录,body 为要更新的字段(如 `{ userPhoto }`),`data` null

### 4.5 提交反馈 ✅
`POST /front/user/feedback` — 需登录,body 为反馈内容字符串,`data` null

### 4.6 评论 CRUD ✅
| 方法/路径 | body | 说明 |
|---|---|---|
| `POST /front/user/comment` | `{ bookId, commentContent }` | 发评论 |
| `DELETE /front/user/comment/{id}` | — | 删评论 |
| `PUT /front/user/comment/{id}` | `{ content }`(form) | 改评论 |

### 4.7 我的评论列表 ✅
`GET /front/user/comments?pageNum=&pageSize=` — 需登录
`data`:分页对象,`list` 元素 `{ commentBook, commentBookPic, commentContent, commentTime }`

### 4.8 我的书架 🆕
| 方法/路径 | 说明 |
|---|---|
| `GET /front/user/bookshelf` | 书架列表(含上次读到章节) |
| `POST /front/user/bookshelf/{bookId}` | 加入/更新书架 |
| `DELETE /front/user/bookshelf/{bookId}` | 移出书架 |

### 4.9 阅读历史 🆕
`GET /front/user/read_history?pageNum=&pageSize=` — 需登录

## 5. 作家后台接口 `/author`(需作家身份)

### 5.1 作家身份状态 ✅
`GET /author/status` — 需登录
`data`:作家对象 `{ id, userId, penName, status, ... }`;非作家返回 `null`(前端据此跳"申请成为作家")

### 5.2 申请成为作家 ✅
`POST /author/register` — 需登录
body:`{ penName, telPhone, chatAccount, email, workDirection }`,`data` null

### 5.3 作品管理 ✅
| 方法/路径 | body | 说明 |
|---|---|---|
| `GET /author/books?pageNum=&pageSize=` | — | 我的作品分页列表 |
| `POST /author/book` | `{ workDirection, categoryId, categoryName, bookName, picUrl, bookDesc, isVip }` | 发布作品 |

作品列表 `list` 元素:`{ id, picUrl, bookName, categoryName, visitCount, updateTime, wordCount }`

### 5.4 章节管理 ✅
| 方法/路径 | body | 说明 |
|---|---|---|
| `GET /author/book/chapters/{bookId}?pageNum=&pageSize=` | — | 章节分页列表 |
| `POST /author/book/chapter/{bookId}` | `{ chapterName, chapterContent, isVip }` | 发布章节 |
| `GET /author/book/chapter/{id}` | — | 章节详情 `{ chapterName, chapterContent, isVip }` |
| `PUT /author/book/chapter/{id}` | `{ chapterName, chapterContent, isVip }` | 修改章节 |
| `DELETE /author/book/chapter/{id}` | — | 删除章节 |

章节列表 `list` 元素:`{ id, chapterName, chapterUpdateTime, isVip }`

### 5.5 AI 写作 ✅
`POST /author/ai/{action}` — 需登录,`multipart/form-data`
- `action`:`expand`(扩写) / `condense`(缩写) / `continue`(续写) / `polish`(润色)
- body:`text`(选中文本)、`ratio`(扩写/缩写比例)、`length`(续写长度)
- `data`:生成的文本字符串

## 6. 支付/订阅接口 `/pay` 🆕(需登录)

| 方法/路径 | 说明 |
|---|---|
| `POST /pay/recharge` | 创建充值订单,返回支付参数/二维码(开发环境用沙箱) |
| `POST /pay/callback/{channel}` | 支付宝/微信异步回调(验签后更新余额与订单) |
| `POST /pay/subscribe` | 购买章节/整本,body `{ bookId, chapterId? }`,扣余额 + 写订阅 |
| `GET /pay/orders?pageNum=&pageSize=` | 我的订单 |
